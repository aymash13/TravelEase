# 🌍 TravelEase – Online Travel Booking Platform

TravelEase is a user-friendly, dynamic online travel booking system designed to simplify and enhance the travel experience for users and agencies. This platform allows customers to explore destinations, view available travel packages, make bookings, and manage their trips—all in one place. An intuitive admin panel enables agencies to manage packages, bookings, and customer data efficiently.

## 🚀 Features

### 👤 User Side
- View and explore travel destinations
- Browse available travel packages with details
- Book travel packages online
- View and manage user bookings
- Auto-fetch user and package details during booking

### 🛠️ Admin Panel
- Dashboard with booking and package statistics
- Add, update, or delete travel packages
- Manage user bookings and update booking status
- Search, filter, and view user & booking details


## 🛠️ Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** MySQL
- **Languages:** JavaScript (used for additional features or backend logic)
- **Tools:** XAMPP for local development
